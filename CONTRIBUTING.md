# Contributing

Issues and pull requests are welcome for the supported Windows x64 SMB1 prototype.

Before opening a pull request:

1. Describe the user-visible behavior and the supported setup it affects.
2. Keep changes scoped to project-owned files; upstream changes belong in tracked patches.
3. Run the build or focused runtime check relevant to the change and record what was actually verified.
4. Check that no ROM, save, state, generated build, user configuration, or secret is included.

See [Building from source](docs/building.md) and [Architecture](docs/architecture.md). Do not report untested Netplay or rollback behavior as verified.
