# Third-party notices

## MesenCE

The emulator core is based on [MesenCE](https://github.com/libretro/MesenCE), pinned to the commit in `config/mesence-revision.txt`, and licensed under GPL-3.0. The project applies a tracked patch at build time; the fetched source and generated core remain local build artifacts.

## RetroArch

RetroArch is a separate GPLv3 frontend distributed by Libretro. The project setup downloads its official portable Windows archive; it is not embedded in this repository.
