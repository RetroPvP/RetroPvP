# Controls

Default keyboard bindings used by the current launcher:

| Player | Action | Default |
| --- | --- | --- |
| P1 | Move | W / A / S / D |
| P1 | A / B | J / K |
| P1 | Start | Enter |
| P2 | Previous / next target | Numpad 7 / 9 |
| P2 | Take over / release target | Numpad 5 |
| P2 | Spawn Bullet Bill | Numpad 0 or right mouse button |
| P2 | Steer | Numpad 8 / 2 / 4 / 6 |
| P2 | A / B | Comma / period |

Use the window's RetroPvP menu to change the P1/P2 bindings. Emulator Hotkeys… configures save/load state, state slots, pause, screenshots, reset, mute, fullscreen, and exit. Volume… adjusts and saves volume. Relay Region… changes the relay location or custom server address.

Fast-forward is disabled in the launcher configuration, including both toggle and hold bindings, so Space cannot accelerate a Netplay session.
