# Security

Do not include credentials, public IP addresses, private relay invites, save states, or ROM files in public issues.

For a suspected vulnerability, use GitHub's Report a vulnerability action on the repository's Security tab. If private vulnerability reporting is unavailable, open a minimal issue asking maintainers for a private reporting channel; do not post exploit details publicly.

RetroPvP is a proof of concept built on pinned upstream projects. Report issues in upstream components to their maintainers as well when appropriate.
